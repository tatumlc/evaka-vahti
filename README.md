# eVaka-vahti

Epävirallinen Android/Termux-pohjainen seuranta omalle lapselle eVakan hoitoaikojen muutoksista ja kirjatuista saapumisista/lähdöistä.

**Aloita:** lue `ASENNUS-JA-KAYTTOONOTTO.md` ja aja `bash ~/evaka-vahti/asenna.sh`.

eVaka-vahdin lähdekoodit ovat kansiossa `src/evaka_vahti/`. Paketti sisältää vain eVaka-vahdin oman ohjelmakoodin ja sen käyttöönottoon tarvittavat tiedostot.

Käyttäjän tunnuksia, henkilötietoja, lokia tai aiempia seurantatiloja ei sisälly tähän jakelupakettiin.
