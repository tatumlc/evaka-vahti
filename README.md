# eVaka-vahti

Epävirallinen Android/Termux-pohjainen seuranta omalle lapselle eVakan hoitoaikojen muutoksista ja kirjatuista saapumisista/lähdöistä sekä uusista eVaka-viesteistä.

**Aloita:** lue `ASENNUS-JA-KAYTTOONOTTO.md` ja aja `bash ~/evaka-vahti/asenna.sh`.

Kolmas tarkistus `./aja.sh viestit` ilmoittaa uusista vastaanotetuista viesteistä (ei viestin sisältöä).

eVaka-vahdin lähdekoodit ovat kansiossa `src/evaka_vahti/`. Paketti sisältää vain eVaka-vahdin oman ohjelmakoodin ja sen käyttöönottoon tarvittavat tiedostot.

Käyttäjän tunnuksia, henkilötietoja, lokia tai aiempia seurantatiloja ei sisälly tähän jakelupakettiin.

Viestivahdin ilmoituksissa näkyvät nyt lähettäjä ja otsikko; vastaukset omiin viesteihin korostetaan.
